### 📌 About The Project
​KGAMER-RETROGAMER is a Raspberry Pi OS Bookworm-based retro gaming console and desktop operating system. It eliminates the need to choose between a retro gaming console and a personal desktop PC, allowing you to instantly access retro game emulators or seamlessly switch to a fully-featured Linux desktop environment for your daily office tasks from a single SD card or USB drive.
​
### ✨ Features

###​ 🎮 Gaming Mode
​Bookworm Graphics Optimization: Low-latency video and audio performance via Wayland and PipeWire integration.
​Wide Emulator Support: Powered by RetroArch for NES, SNES, PS1, PSP, N64, Sega, Arcade, and more.
​Gamepad Support: ⚠️ Gamepad/controller support is currently NOT available. Controls are keyboard/mouse only for early builds. Gamepad support will be added in future updates.

​### 🎁 Bonus Pre-Installed Games
​BONUS: BEE GOLD COLLECTOR HERO EDITION PORT included pre-installed out of the box!

​### 💼 Office Mode
​Lightweight Desktop: Fast, responsive desktop environment optimized on Raspberry Pi OS Bookworm.
​Office Suite & Media: Pre-installed LibreOffice, Chromium browser, YouTube playback support, and VLC media player.
​

### 📥 Installation Guide (Raspberry Pi Imager)
​Download and open Raspberry Pi Imager.
​Click [ CHOOSE DEVICE ] and select your model.
​Click [ CHOOSE OS ] ➔ Scroll down ➔ Select Use Custom ➔ Choose your downloaded KGAMER-RETROGAMER.img file.
​Click [ CHOOSE STORAGE ] and select your MicroSD card or USB drive.
​Click [ WRITE ].
​Important Note: Since a pre-configured user account is already embedded inside the image file, when Raspberry Pi Imager prompts you with the OS customization settings window, click "No" / "Skip" to bypass it.

### ​📥 Kurulum Rehberi (Raspberry Pi Imager)
​Raspberry Pi Imager programını indirin ve açın.
​[ CHOOSE DEVICE ] kısmından cihazınızı seçin.
​[ CHOOSE OS ] ➔ En alta inip Use Custom (Özel Kullan) seçeneği ile .img dosyanızı gösterin.
​[ CHOOSE STORAGE ] ile SD kartınızı veya USB belleğinizi seçin.
​[ WRITE ] (Yaz) butonuna tıklayın.
​Önemli Not: İmaj dosyasının (.img) içerisinde zaten hazır bir kullanıcı hesabı gömülü olduğu için, Raspberry Pi Imager'ın sunduğu özelleştirme penceresi geldiğinde "No" (Hayır) diyerek / "Onu atla" seçeneğini kullanarak bu pencereyi geçin.
